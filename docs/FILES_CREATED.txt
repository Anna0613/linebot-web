================================================================================
  ⚠️ 重要提醒
================================================================================

1. 環境變數安全
   - 所有 .env 檔案不應提交到版本控制
   - 保護檔案權限: chmod 600 .env

2. 資料庫配置
   - 本伺服器已有 PostgreSQL 服務: /mnt/user/appdata/postgresql15
   - 需要確認資料庫和用戶已建立

3. 敏感訊息
   - JWT_SECRET, 密碼等需要替換為實際值
   - 建議使用強密碼和隨機密鑰

4. 依賴服務
   - Redis: 用於會話和快取
   - PostgreSQL: 主資料庫
   - MongoDB(可選): 對話記錄
   - MinIO(可選): 媒體存儲
